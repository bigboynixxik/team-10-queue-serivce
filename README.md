# Авито Очередь (MVP)

## 1. Контекст проблемы
На платформе регулярно появляются лимитированные или дефицитные товары (редкие позиции, распродажи), спрос на которые многократно превышает доступное количество. Из-за асинхронной работы процесса оплаты возникает проблема: несколько пользователей могут одновременно начать оформлять заказ на один и тот же товар.
В результате количество оформленных заказов превышает фактический остаток на складе. Пользователь тратит время на оформление, но в конце узнает, что товар недоступен. Это вызывает негатив, снижает лояльность к платформе и создает повышенную нагрузку на системы.

## 2. Бизнес-цель
Создать MVP сервиса пользовательской очереди, который:
1. Ставит покупателя в очередь перед переходом к оплате.
2. Защищает систему от некорректного распределения товаров (исключает возможность одновременной покупки одной единицы товара несколькими людьми).
3. Выдает временное и защищенное право на покупку.
4. Органично вписывается в существующий путь пользователя на платформе.
