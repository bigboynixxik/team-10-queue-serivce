# Диаграмма контекста C4 (Уровень 1)

Диаграмма описывает взаимодействие пользователей с сервисом «Авито Очередь» и то, как наш MVP встраивается в экосистему основной платформы Авито.

```mermaid
flowchart TD
classDef person fill:#08427b,stroke:#052e56,color:#ffffff,font-weight:bold,rx:50,ry:50
classDef system fill:#1168bd,stroke:#0b4884,color:#ffffff,font-weight:bold,rx:10,ry:10
classDef external fill:#999999,stroke:#6b6b6b,color:#ffffff,font-weight:bold,rx:10,ry:10

%% Акторы и Системы
User("Покупатель\n[Пользователь]\nПользователь, желающий приобрести лимитированный товар"):::person

System_Queue("Сервис «Авито Очередь»\n[Программная система]\nУправляет листами ожидания, защищает стоки и выдает права на покупку"):::system

System_Avito("Платформа Авито\n[Программная система]\nПредоставляет каталог товаров, профили и платежный шлюз"):::external

%% Связи (Функции взаимодействия)
User -- Встает в очередь, отслеживает свой статус и получает эксклюзивное право на покупку --> System_Queue
User -- Ищет дефицитные товары в каталоге и завершает оформление заказа --> System_Avito
System_Queue -- Запрашивает информацию о доступности лимитированных товаров и их остатках --> System_Avito
System_Avito -- Перенаправляет поток пользователей при попытке купить дефицитный товар --> System_Queue
